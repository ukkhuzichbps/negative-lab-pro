## Overview

Negative Lab Pro is a Lightroom plugin that transforms scanned film negatives into beautifully rendered positive images using advanced color science and tone mapping algorithms.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Negative Lab Pro** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **One-Click Convert** | Intelligent negative inversion preserves color balance and film character |
| **Profile Library** | Film emulation profiles for major color negative and slide films |
| **Color Tone** | Fine-grained color temperature, tint, and shadow tone adjustments |
| **Non-Destructive** | All adjustments stored in Lightroom metadata, no pixel changes |
